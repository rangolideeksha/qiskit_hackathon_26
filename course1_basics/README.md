# Course 1 — Basics of Quantum Information

Working folder for the [Basics of Quantum Information](https://quantum.cloud.ibm.com/learning/en/courses/basics-of-quantum-information) labs (Hours 1–6 of the [study plan](../docs/study_plan.md)).

Runnable reference implementations you can copy from:

- Hour 4 (circuits & statevectors) → [`examples/bell_state.py`](../examples/bell_state.py)
- Hour 5 (teleportation) → [`examples/teleportation.py`](../examples/teleportation.py)

Drop your own lab notebooks/scripts here as `hourN_topic.py`. Run anything with:

```bash
uv run python course1_basics/your_file.py
```
