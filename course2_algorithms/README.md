# Course 2 — Fundamentals of Quantum Algorithms

Working folder for the [Fundamentals of Quantum Algorithms](https://quantum.cloud.ibm.com/learning/en/courses/fundamentals-of-quantum-algorithms) labs (Hours 7–15 of the [study plan](../docs/study_plan.md)).

Runnable reference implementations you can copy from:

- Hour 9 (query algorithms) → [`examples/deutsch_jozsa.py`](../examples/deutsch_jozsa.py)
- Hours 10–11 (QFT / phase estimation) → [`examples/qft.py`](../examples/qft.py)
- Hour 14 (Grover) → [`examples/grover.py`](../examples/grover.py)

Drop your own lab notebooks/scripts here as `hourN_topic.py`. Run anything with:

```bash
uv run python course2_algorithms/your_file.py
```
